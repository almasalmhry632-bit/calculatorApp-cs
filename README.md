🧮 Calculator App V1

A simple console-based calculator developed using C#.

📌 About the Project

Calculator App V1 is a simple console application created to demonstrate fundamental programming concepts and logical thinking through basic arithmetic operations.

The project focuses on implementing calculation logic using C# without a graphical user interface.

🛠️ Technologies Used

- C#
- .NET
- Visual Studio

💡 Key Concepts

- Variables and data types
- User input and output
- Conditional statements
- Arithmetic operations
- Basic programming logic

🚀 Project Evolution

This project represents the first version of my calculator application.

It served as the foundation for Calculator App V2, which introduced a graphical user interface built with Windows Forms.
